# Business Booster Services

A simple business-services website built as my **first self-made web development project**.

The website presents services such as web development, Google Business Profile optimisation, SEO, and AI automation through a multi-page business website.

## 🚀 About the Project

This project was created to practice building a complete website from scratch using HTML and CSS.

It includes:

* Responsive navigation
* Home page with a hero section
* Services section
* Pricing page
* Contact page
* Responsive layouts for different screen sizes
* Hover effects and interactive styling
* Font Awesome icons
* Custom CSS variables and responsive media queries

## 🛠️ Built With

* HTML5
* CSS3
* Font Awesome
* Google Fonts

## 📁 Pages

* `home.html` — Main landing page
* `service.html` — Services
* `pricing.html` — Pricing
* `contact.html` — Contact

## 🎯 What I Learned

While building this project, I practiced:

* Structuring webpages with HTML
* Creating layouts with CSS Flexbox and Grid
* Using CSS variables
* Building responsive designs with media queries
* Creating hover effects and transitions
* Connecting multiple HTML pages through navigation
* Organising a website into separate files

## 📌 Project Status

This is my **first self-built website**, so it is still a learning project and will likely be improved as I learn more about web development.
